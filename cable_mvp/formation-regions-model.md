# 编队分区模型（复核版）

## 8. 距离 × 载重分区：独立单航段情景

输入为同一航段距离 R 与本机载重 q；它不等于 A→C→B 主任务，也不证明全编队的领航机可以完成同一超程任务。面板参数独立设置，主任务失败不阻塞它。

能量假设 E=(k0+k1 q)R。让 (70 km,20 kg) 与 (110 km,10 kg) 耗尽同一预算，可以得到 k1=2k0/15、Emax=(k0+20k1)70。k0 为情景假设，这不是实测电池容量。此式只通过两个参考点，**不重现原论文整条线性载重曲线**：例如 q=15 时本拟合为 85.56 km，原曲线反解为 90 km。

等待耗能 Ewait=loiter·(k0·speed/60)·delay，单位 kWh。盘旋率忽略载重、转弯与风场，仅为可替换的近似。等待费用与电量都要扣除：

```text
单飞：E ≤ Emax
编队：γE + Ewait ≤ Emax
双方：q ≤ payload_limit（默认净货物上限 20 kg）
不允许外推时：双方 R ≤ 110 km
单飞边界：Emax/(k0+k1 q)
编队边界：(Emax−Ewait)/[γ(k0+k1 q)]，Ewait>Emax 时无可达航程
```

两条边界使用相同范围限制；允许外推时双方一同放开 110 km 范围，但结果均未实机验证。零节能、零等待时边界必须重合。零载重也不代表无限航程。图外边界保留其实际数值，不截为绘图边界假装“最远”。

```text
编队成本优势 A = p_e[(1−γ)E−Ewait] − v_time q delay − C_coord
经济平衡 R* = [v_time q delay + p_e Ewait + C_coord]
             / [p_e(1−γ)(k0+k1 q)]
```

分母为零时没有有限平衡距离。仅当双方均可达时，A>0 才表示编队更省；平衡距离在可达域外，不表示可以飞过去获利。五类区域分别为双方可达单飞不贵、双方可达编队更省、仅编队可达、双方不可达/范围外、仅单飞可达（等待耗电）。采样点占比不是实际需求概率。

默认 m=3、η=0.10、χ=0.6（χη=0.06）、delay=6.5 min 时 γ=0.96，等待电量 0.2925 kWh。20 kg 的单飞边界 70.00 km，计入等待后的编队边界 69.59 km——**比单飞还短 0.41 km**。允许外推时 10 kg 为 110.00 与 109.36 km，5 kg 为 154.00 与 153.10 km，同样都是编队略短。经济平衡距离在可达域之外（20 kg 约 611.6 km、10 kg 约 543.2 km、5 kg 约 468.0 km）。

这不是算错：χη=0.06 时每公里只省 0.04·rate kWh，在 20 kg 下要飞约 80 km 才能省回一次 6.5 min 的盘旋等待（0.2925 kWh），而该载重的航程上限恰好只有约 70 km。**结论是：在默认等待时长下，气动节能不足以补偿盘旋等待。** 这条结论对等待时长比对 χη 敏感得多，把 delay 调小或关掉 loiter，编队边界立刻回到单飞之上。

χ·η=0.06 是情景参数乘积，不是本机实际节能比例。在 m=3 的跟随公式中，实际巡航节能为 χη(m−1)/m=4%。**原稿写的「χη ∈ [0.10, 0.18] 文献标定区间」在 2026-09-26 的页码级核查后被推翻**：构成区间的数字几乎全是二次引用的军机/运输机燃油数据，没有一条是 96 kg 级电动垂起固定翼的一手值。面板新增 χη 扫描表（0.02–0.18），把区间本身作为可检查的对象。详见 `winch-model.md`、`handoff-audit-2026-09-26.md` 与下载包内 `docs/aero-sources-verified.md`。
