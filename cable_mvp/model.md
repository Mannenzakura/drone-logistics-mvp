# 单机编队衔接期间索降装卸：最小可行模型

版本：2026-09-23。用途：验证机制与盈亏条件；不是经过实机标定的飞行方案。除明确标注的原文参数外，数值均为演示假设。新模型符号不冒充原论文符号。

**2026-09-24 公开数据复核：**本文件第 5—7 节的数值最优解仍然只是说明算法的假设算例。新增查到的绞盘规格和投送时间不能代入同一机型直接证明其性能。来源、适用范围及更新后的物理筛选见 [公开数据更新](public_data_update.md)。尤其是，原版将“卸货并装货”作为一个固定作业周期；厂商公开资料没有证实这种同一悬停内换货流程。若采用先投送后取货的流程，应按两道操作分别计时，并重新求解。

## 1. 数据依据与适用范围

《基于网络流优化的低空物流网络容量研究》，用户文件《深大学报原文.pdf》：PDF 第 8 页表 2，丰舟 90（K3）为 20 kg/70 km、10 kg/110 km，巡航速度 108 km/h；第 10 页式 (24) 为 w₃(dᵢⱼ)=37.5−dᵢⱼ/4，0≤dᵢⱼ≤110 km。距离单位 km，载重单位 kg。这里原式 dᵢⱼ 表示距离，和本模型卸货量 d 不同。

厂商机型列表 https://www.fyuav.cn/uav/ 将丰舟 90 标为“垂起固定翼物流无人机”（2026-09-23 查询）。这只确认基本构型，不证明该产品已有索降改装、空中重组或编队节能能力。

原文的载重—航程曲线不是能耗方程，不能从其斜率 1/4 推出 kWh/kg，也不能分别检查两段航程后就宣称整个任务电量够用。本算例借用 70 km 对应 20 kg 作为参考载荷上限，同时单列必须标定的任务电量余量。借用该上限是新增模型假设，不构成改装后性能保证。原文函数在短距离处的外推值也不能直接当作实际结构承重上限。

## 2. 固定任务与比较基准

同一架已经装有索降设备的无人机，从 A 经 C 到 B，在预先确定的时间加入 C→B 编队；该编队有确定的空余位置，加入这架飞机不改变其他飞机的时刻。固定 q kg 的 A→B 货物放在常规货仓。决策为在 A 的可拆卸仓预装 d kg 的 A→C 货物，在 C 全部卸下，再装 l kg 的 C→B 货物。仅作业一个放仓—收仓循环。允许只卸、只装或不作业。

基准：仍携带 q、沿相同路线、等相同时间、加入同一支编队，但 d=l=0。索降设备自重在两方案中都存在。本模型比较单次运营增益，不涵盖设备采购和认证成本；部署决策还需将这些成本分摊进去。

基准若是盘旋而作业需要悬停，转换与额外悬停的能耗差必须计入增量能耗。不能因为有等待时间就把悬停看成免费。本版将不同等待阶段、载重、模式转换的影响用局部线性系数汇总；这是待标定近似。

新增货物需求为可选择服务的需求，而不是必须完成的全网订单。固定 q 不允许被挤占；因此暂不包含满载时替换其他订单的机会成本。若任务要求相同的一组订单全部送达，则必须加入其他配送方式的成本作比较，不能再用本算例的新增收入直接判断系统节约。

## 3. 参数、变量与单位

|符号|含义|单位|
|---|---|---|
|d,l|分别为 A→C 卸货量、C→B 装货量，连续变量|kg|
|z|是否启用一次索降装卸循环，0 或 1|无量纲|
|q|固定 A→B 常规货仓货量|kg|
|Q|已扣除新增设备/空仓质量后的任务参考货物上限|kg|
|B|可拆卸仓货物载重上限|kg|
|D,L|分别可接受的 A→C、C→B 需求上限|kg|
|W|从到达 C 到必须结束作业的时间，已扣除重新入队及安全缓冲|min|
|H|调度方预留的不与其他起降、进离场航迹冲突的连续作业窗口长度|min|
|a|该任务是否已获兼容空间与窗口，0 或 1|无量纲|
|t₀|一次作业固定时间，含接近、转换、放仓、收仓、撤出等固定部分|min|
|t_d,t_l|每 kg 卸货、装货的增量时间| min/kg |
|e₀|相对基准的一次作业固定增量耗能|kWh|
|e_d,e_l|每 kg 新增卸货、装货对应的全任务增量耗能|kWh/kg|
|G|基准任务结束仍可用于新增作业的电量，已扣除规定备用量|kWh|
|r_d,r_l|单位新增运输服务收入或可核实的服务价值|货币单位/kg|
|h_d,h_l|单位新增非能源可变成本|货币单位/kg|
|p_e|电能单位成本|货币单位/kWh|
|F₀|每次作业非能源固定成本|货币单位|
|b_d,b_l|单位新增净贡献，b_d=r_d−h_d−p_e e_d，b_l=r_l−h_l−p_e e_l|货币单位/kg|
|F|总固定增量成本，F=F₀+p_e e₀|货币单位|

Q 同时约束两段总货物；需另外确认常规货仓能放 q。仓体体积、重心、包裹尺寸暂假设满足要求，kg 连续化只适用于可分货物或聚合近似。标准仓在卸后回装，所以应为 d≤B、l≤B，而非 d+l≤B。

e_d 包括在 A→C 携带 d 的巡航增量，以及等待和作业的载重影响；e_l 包括 C→B 编队飞行携带 l 的增量及有关悬停影响。两者不能由原论文的航程系数换算。本版不额外计入编队节能奖励，因为两方案均加入同一编队；编队状态应体现在已标定的 e_l 和基准任务电量中。

## 4. 数学模型

最大化相对基准的单次净收益：

    max ΔΠ = b_d d + b_l l − F z

约束：

    0 ≤ d ≤ D z,   0 ≤ l ≤ L z
    d ≤ B z,       l ≤ B z
    q + d ≤ Q,     q + l ≤ Q
    t₀ z + t_d d + t_l l ≤ W
    t₀ z + t_d d + t_l l ≤ H
    e₀ z + e_d d + e_l l ≤ G
    z ≤ a,         z ∈ {0,1}

必须先确认 q≤Q、基准任务可飞且编队位置已预约；否则应报告“基准任务不可行”，不能返回 d=l=0 冒充可行。参数 W,H,G 均非负。

空域条件的含义是：调度方已经确认一块兼容的空间及连续窗口，时间长度 H 本身不能证明空间无冲突。选用保守安排时，预留窗口从到达开始，覆盖完整作业及撤出。若实际窗口中途开始，应先扣除等窗口的时间并重新构造 W；多窗口不可直接把长度相加。a=0 时必须不作业。

本版以外生兼容窗口和固定衔接时刻确保“不侵占其他起降服务、不误下一支编队”。这是条件化约束，并非证明了全网容量不下降。实际冲突检查、风场、吊索摆动与多机协同尚未建模。

这是一个只有一个二元变量的混合整数线性模型。分别固定 z=0、z=1：前者是不作业，后者是二维线性规划；枚举全部边界交点可求全局最优。连续载重设定下无需复杂算法，也不需要现在引入博弈论或排队论。

## 5. 演示算例：原文数据与假设严格分开

原文：丰舟 90 巡航 108 km/h；70 km 对应 20 kg。选取 A→C=30 km、C→B=40 km（两段距离均是假设），水平巡航共约 38.89 min，不含起降、等待和转换。

其余均是假设：参考 20 kg，暂扣设备/空仓增重 2 kg 得 Q=18 kg；q=10 kg；常规仓容纳 q；B=5 kg；D=L=5 kg；已获兼容连续窗口 a=1，W=H=6 min；t₀=2 min，t_d=0.4 min/kg，t_l=0.6 min/kg；e₀=0.1 kWh，e_d=0.04 kWh/kg，e_l=0.08 kWh/kg；G=0.65 kWh；净贡献 b_d=4、b_l=3 货币单位/kg，F=5 货币单位。

这些成本是已扣除变量能源等成本的净贡献，目标函数不得再扣一次相同电费。G 是假设的基准外剩余预算，绝不是原文电池容量。新增能量系数只是检验程序和展示盈亏逻辑的数值，没有实机依据。

上述 6 min 已扣除重新入队缓冲；如果实际总等待只有 6 min，必须先扣缓冲再用。设备重量也是待查项，不能认定丰舟 90 真的可以加装该设备。

2026-09-24 复核后的设备参照：A2Z 当前 RDS2 页面列绞盘主体质量 1.5 kg、自动释放钩及配重 0.264 kg，合计 1.764 kg；但两种产品是否兼容、仓体及安装件质量未知。故本算例“新增设备共 2 kg”不能认为已由这两个公开数字验证，甚至可能偏低。A2Z 同一页面对当前版本列投送、取货均至多 5 kg；它是另一厂商绞盘的能力，不是丰舟 90 的已认证可拆卸仓能力。

## 6. 手算最优解

时间约束化为 0.4d+0.6l≤4。每分钟净贡献分别为 4/0.4=10、3/0.6=5，卸货优先。本算例卸货还具有更高的单位增量能耗净贡献，因此不会因能量约束而倒置优先级。

先取 d=5，剩余装货时间 2 min，因此 l=10/3≈3.333 kg。

    ΔΠ = 4×5 + 3×(10/3) − 5 = 25 货币单位/次。

这可直接证明最优：4d+3l=2d+5(0.4d+0.6l)≤2×5+5×4=30；该解达到上界，扣固定成本 5 得 25。再检查能量和其他条件可行，故为演示模型的全局最优解。

|核验项|计算结果|上限/余量|
|---|---|---|
|A→C 货物|10+5=15 kg|Q=18，余 3 kg|
|C→B 货物|10+10/3≈13.333 kg|Q=18，余约 4.667 kg|
|可拆卸仓出发/离开 C|5 / 3.333 kg|分别≤5 kg|
|作业总时长|2+0.4×5+0.6×10/3=6 min|恰好用满作业窗口|
|新增能量|0.1+0.04×5+0.08×10/3≈0.5667 kWh|0.65，余约 0.0833 kWh|
|新增交付量|d+l≈8.333 kg|两条不同 OD 订单的合计，不是同时在机载重|
|不作业收益|0|作业提高 25 货币单位|

任务前后分别增加 d、l，不是凭空释放永久载荷。该解在 C 净减载 d−l≈1.667 kg，但也完全可能在其他参数下 l>d、离开 C 更重；最优性不能预设必须净减载。

正收益来自利用已有行程和等待窗口承接额外订单，扣除新增成本后还有余额。这里不能再额外加“卸掉 d 后整个 C→B 节省的能耗”作为收益：基准原本只带 q，未携带这批 C 货物继续飞往 B。

## 7. 盈亏阈值与下一步

记固定 z=1 的可行域为 S。如果 S 为空则不作业；否则计算 V=max_(d,l)∈S (b_d d+b_l l)。最优单次收益为 max(0,V−F)，正收益当且仅当 V>F。

主算例 V=30，所以 F<30 时正收益，F=30 时作业与不作业同样好，F>30 时不作业。这里只改变成本，不改变作业时间和耗能。若两个净贡献同乘 α，临界 α=1/6。

H 保持 6、其他参数不变时，增大 W 超过 6 不会再有收益提升，因为兼容空域窗口先卡住。W=H 同时延长也不一定一直有用，之后可能由电量、需求或货仓接替成为瓶颈。短等待是否值得作业还取决于固定成本，而非只要装卸得下就一定值得。

优先补数据：①两段距离、实际到达和入队时刻及必要缓冲；②兼容索降位置与连续窗口是否存在；③改装后净载荷、常规仓与可拆卸仓质量/体积容量；④完整作业周期以及随卸/装重量变化的时间；⑤相对无作业基准的任务能量差与备用电量；⑥两个 OD 的真实需求和单位净贡献。前四项决定时间与载荷可行性，第五项决定续航，第六项决定经济性。

可以先取得多个载荷组合的“基准/索降任务”仿真或试验差值，再拟合 e₀,e_d,e_l；如果残差大或有明显非线性，应升级为分段线性/非线性模型。没有实测前，报告只可表述为“存在正收益的参数区域”，不可表述为“真实丰舟 90 索降一定盈利”。

## 8. 复现

运行同目录 solve.py；仅需 Python 标准库。Fraction 有理数精确枚举全部二维顶点，对两个 z 分支求最优；另以独立写出的业务约束核验返回解。输出 result.json（精确分数及浮点值、约束剩余量、边界测试和敏感性），sensitivity.csv。输入见脚本 BASE 字典。该字典中除巡航速度、参考载荷点、参考航程外均为演示假设。
