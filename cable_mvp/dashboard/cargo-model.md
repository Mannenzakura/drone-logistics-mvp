# 分货舱、分运输任务的经济模型（取代 economics-model.md 旧公式）

q：常规货舱，A→B 必运货物，用户定义 kg 数。
d：可拆卸仓，A→C 卸货，0≤d≤D。
l：同一个可拆卸仓卸空后，C→B 新装货，0≤l≤L。
D、L 是需求上限，不是已经装入的重量。手动模式可指定 d、l。
d 和 l 不会同时占仓，因此各自不超过仓容量 B，不要求 d+l≤B。

三组分别选择类型并定义 r_i（货运收费，货币单位/kg）、v_i（时效损失系数，货币单位/(kg·min)）和 h_i（处理成本，货币单位/kg）。价格不是商品价值。每组当前代表一种货物或一批同质货物，不含仓内多品类装箱。

类型预设均为可修改的演示假设。旧 API 的 cargo_type、cargo_fee、time_value、handling_cost 仍可批量初始化；cargo_types 中 q/d/l 指定单独类型，parameters 中 fee_q/d/l、time_q/d/l、handling_q/d/l 单独覆盖。

固定编队发车时刻：T_q=T_AC+W+b+T_CB，T_l=W+b+T_CB（假设 l 在本机到达 C 时已备妥）。T_d=T_AC，按到达 C 记交付，暂忽略卸货过程造成的时效差异。这些时间与装卸量无关，故目标为线性；等待 W 不可替换成实际操作时间。

收入 R=r_q q+r_d d+r_l l。
时效损失 C_t=v_q q T_q+v_d d T_d+v_l l T_l。
处理成本 C_h=h_q q+h_d d+h_l l。
巡航和固定作业能耗 E=e_empty R_AC+a_d(q+d)+γ[e_empty R_CB+a_l(q+l)]+e0 z。
净经济效益 Π=R−C_t−C_h−p_e E−Fz。
E 暂无独立悬停功率、维护折旧和起降能耗模型；这是已列成本口径下的估算，尚非完整运营财务利润。

自动优化与上述 Π 使用同一组边际系数：
c_d=r_d−v_d T_d−h_d−p_e a_d；
c_l=r_l−v_l T_l−h_l−p_e γa_l；
固定装卸成本 F+p_e e0。
q 固定，其收入、时效和能耗为常数，不改变 d/l 最优选择。原物理和能源余量约束保留，精确枚举二维线性规划的顶点及两种 z 状态。

直飞 A→B 只运同一批 q，并使用 q 的价格/时效/处理成本。C 起运的 l 不能无条件放到 A，也不能在直飞时服务 C 目的地的 d。页面差额比较不同服务范围的单架次情景；当 d=l=0 时才是同一批 q 的路线对照。直飞可行性目前是参考航程和载荷筛选，不是电池与飞控验证。
