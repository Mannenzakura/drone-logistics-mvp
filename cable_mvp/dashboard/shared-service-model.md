# C点共享作业设备最小模型

索引 i 表示中转飞机，a_i 为到达C时刻（分钟），w_i 为装卸作业时长（分钟），m为设备数量（整数1至20）。两条出站分支共用m台设备，设备初始在0分钟空闲，作业不可中断。依到达时刻排序，同刻按全局飞机编号；每架选择最早空闲的设备k：开始 s_i=max(a_i,设备k空闲时刻)，结束 f_i=s_i+w_i，更新设备空闲时刻为f_i。零时长作业直接通过，不占设备，也不因设备繁忙而延迟。设备排队时间为s_i−a_i；可入编时刻为f_i+入编缓冲。后续仍按各出站航线的严格FIFO和当班剩余位置衔接。

这是有限样本的多设备FCFS离散排程，不使用稳态等待公式。目标机dC、lC决定其w_i；每个搜索候选均重排两个分支在C的共同作业队列。选定最优方案后，另一路径也以该目标机作业时长重新排程。目标函数仍是目标机运输收入减时效、装卸、固定和电费；设备等待计入总滞留和盘旋耗能，不额外重复扣费。既有sharedC开关指空域许可约束，与共享设备开关是不同概念。

默认共享设备开启，1台；背景中转飞机默认C作业2分钟，均为可修改演示假设。设备关掉则恢复每机到达即作业。每次候选排程复杂度约O(n log n+nm)，n≤48，m≤20；经济优化仍采用有限网格搜索，不声称连续全局最优。

本阶段不让随机本地起飞需求占用这些索降设备，因为该需求尚无逐架装卸时长；不模拟设备故障、共享空域/停机位和设备资本运营成本。下游D/E设备仍独立。专题扰动试验只扰动所选路径，另一分支按当前到达表和作业时长固定，但它仍参与共享设备争用。因此该试验不是全网络随机扰动。未完成或电量不够的候选继续判为不可行。图表、单飞与编队对照都使用同一共享设备规则。
