所选分支路径研究专题

等待主任务计算。

点击“优化并应用”后，以下专题仅针对目标机所选路径及其同路飞机，使用同一组已应用参数；不代表全网优化。分支站代表目标所选的 D 或 E。分区是离散情景扫描，灰色不可行可能来自航程、载荷、班次、电量或空域限制。

所选路径索降可行与盈利分区

扫描 C 卸货 dC 与 C 装/分支站卸货 lC，每格按主模型步长重新优化 分支站装货 lD，并重新排所有中转点班次。增益基准为同一已应用路线、仅运 q、两站均不索降的任务。该基准不可行时，只报告方案可行和任务净收益，不宣称新增业务盈利。

灰：不可行　橙：可行但增益≤0　绿：新增业务增益>0　蓝：基准不可行

所选路径编队与单飞：距离 × 载重分区

两种方案使用相同的当前已应用路线、q 和当前最优 dC/lC/lD。编队按各中转点的 FIFO 班次衔接；单飞完成本站作业后即可离开，不等编队。单飞仍计本站作业时间和耗能。收益差包含等待代价与节能；这不是直飞 A→B，也不是分别改变货量后的利润对比。改上限后点击“重算专题”。

灰：均不可行　绿：仅编队可行　橙：仅单飞可行　蓝：两者可行且编队净收益更高　粉：两者可行且单飞不差

突发扰动试验

保持当前最优 dC、lC、lD 不变，给每架飞机加入随机晚到、作业超时、C→分支站 额外飞行时间，并可随机取消班次。每次都重排所有中转点的 FIFO；本试验只扰动所选路径；同一个种子可以复现结果。百分比是这个情景下的模拟频率，不是实际事故概率。

改动后点击上方“重算专题”。平均净收益仅统计抵达 B 且未超出可用电量的试验；抵达率和电量内可执行率分别展示。C→分支站 额外时间的耗能暂按盘旋率估算。
