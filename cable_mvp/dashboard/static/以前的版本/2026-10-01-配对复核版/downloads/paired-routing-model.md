# 配对路线实验与独立复核

本模块使用已有连续本地到达、跨班积压和C点共享设备排程，不引入新物理参数。优化训练仅使用当前主模型种子。对目标机经D和经E，分别在这一训练样本上优化装卸方案，再固定两份方案。其他飞机路径、到达、作业、设备及班次保持相同；改变目标路径会真实改变C点争用和后续FIFO，而不改变各航线的本地随机流。

选择阶段用R个相同试验种子评估两条路线，逐次配对。已可执行定义为排程抵达B且总能耗不超过电池扣备用后的上限。未抵达不捏造后续能耗或净收益；抵达但超电量不确认可执行利润。已服务等待包含C和中转站总滞留。收益均值仅针对可执行样本，因此不是包含失败损失的期望利润；本模型没有故障迫降、弃货罚款和救援成本。

推荐规则为词典序：可执行次数越多越好，次数并列则比较可执行样本的平均净收益，然后比较抵达者的P95总滞留，最后D优先。这是展示可靠性—收益取舍的启发式规则，不是已证明的随机全局最优策略。若两路均无可执行样本，不推荐推广；训练样本不具备可行装卸方案的路线列出原因，不伪造重复结果。

配对差值定义为E−D。可执行差值每次为-1/0/1；净收益与能耗差只在该次两路线都可执行时计算，必须报告共同可执行的配对次数。平均差的约95%区间用样本标准差/√R乘1.96；只作正态近似，少于2个配对或所有差值相同时不提供区间，避免零变动样本被解释为确定性零风险。路线单独成功率采用Wilson约95%区间，允许全成功样本仍有不确定性。

推荐选定后，再用R个独立、不重叠的种子复核推荐路线。复核不再改路线或优化货量，也不因复核变差重新挑选；显示可执行率、Wilson区间、条件收益与长等待。如果复核无可执行样本，应降低装卸负担或重新设计任务，而非隐藏失败。生成种子会跳过训练种子，复核还跳过选择阶段全部种子；导出JSON记录实际逐次种子、完整参数、固定方案、选择与复核结果。

默认各阶段R=100，选择总种子24，复核总种子100024，可修改。数值仅在当前模型假设和参数范围内有效。默认不是实测可靠性。阶段性成功率是随机需求变化的模拟频率，不是事故率；固定模式没有随机容量，重复结果不提供新的物理证据。点击应用推荐路线将用该实验已经应用的参数切换沙盘；未应用的表单编辑不被静默覆盖，需先应用或恢复表单。
