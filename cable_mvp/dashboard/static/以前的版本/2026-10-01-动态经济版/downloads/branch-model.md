# 最小分支网络：A→C→D/E→B

节点集合 {A,C,D,E,B}，航段集合 {AC,CD,CE,DB,EB}。D/E 位于不同方向，图形位置只表示连接关系；航段距离分别以 km 输入。每架飞机指定分支 D/E 和终点本分支站或 B。终点为 B 不意味着下一站相同：C→D 与 C→E 不共用容量。

## 排程

在每条有编队的有向航段上独立执行严格 FIFO。先按到达排序，再检查队首完成作业并满足目标机衔接缓冲，符合时才消耗本班中转空位。队首未就绪时不允许后机插队。终点站交付完成后退出链；不返航。上一站实际发车时刻加距离/速度×60 得到下一站到达，因而沿真实分支传播晚点。

四条航段分别使用独立随机流与可调本地需求概率。L=1+Binomial(M-R-1,p)，K=M-R-L。L 为本地机，包含领航；M 为规模上限；R 是留空位。本地机优先，未接纳的中转机等下一班。相同种子可复现；各候选方案共用同一名单。发车时刻、中转到达与指定路径仍是输入，不是自动航线选择或未知未来下的随机最优策略。全部概率与距离默认均为演示假设。

## 目标机装卸与经济

目标机必须终点 B，可选择经 D 或 E。把所选分支站视为已有四站优化模型的第二中转点，复用原载荷约束、航程参考、索降时间/空域约束、电量和备用电量限制，并网格搜索 C 卸货 d、C 装货 l1、分支站装货 l2（kg）。C 装货在所选分支站卸下。每段以实际班次编队人数计算原节能函数。

收入为各货组重量乘运输收费；扣除时效损失、处理费、固定索降费和电费。距离用 km、时间 min、能耗 kWh、货量 kg、费用元。这里只计算目标飞机，不能解释成整个网络利润。未服务背景飞机不当作零等待；未达 B 或超电量的目标候选不算可行。给出同货量本路径与直飞对照。高级 JSON 可改已有模型的作业、能耗、载荷、需求和费用参数；D 后缀字段在目标走 E 时表示 E 点，避免误以为仍在 D 作业。

## 边界与验证

两分支独立，暂不争用 C 公共空域和索降设施，也没有本地积压队列、航线选择、随机时刻生成、机场库存、充电或全网货物优化。最小原型的动态画面使用算出的排程驱动运动，不是可随时注入控制的新实时引擎。

复杂度主要为三装卸变量离散网格候选数×FIFO 排程；最多 48 架/班次列表，复用现有软件边界。测试包含分支容量隔离、D 零空位不影响 E、终点退出、E 目标经济、非法路径、种子复现和账本恒等式。原链式模型保留作基线。

## 功能保留更新
最远参考航程、装卸效率、能耗、费用与绞盘等已有参数恢复为直接输入；所选路径研究专题复用已验证的链式方法，保持同一分支名单和种子。其 FIFO/扰动表使用全网飞机编号映射，但只包含所选分支。以前的版本统一放在同名目录，主导航只有一个历史入口。

## 动态账本与界面（2026-10-01）
恢复计划经济对照卡片、货组明细、计划/当前成本表，以及随时间推进的载货、盘旋等待、耗电和编队节能指标。动态账本在货组卸载/终点交付后确认其运输收入；处理成本在相应装卸完成时计入，固定索降成本与能耗在到站时计入；时效损失沿用原计划的运输时段并随时钟累计。这是本模型的展示记账假设，不是实际财务确认规则。全部货组费用仍与原优化模型一致。

任务结束时，累计能耗、总收费、时效损失、处理费、固定费和净收益必须与计划结果逐项一致。中途余额可能为负，计划净收益不会因播放而变化；修改参数并应用后则重新优化和更新计划卡片与表格。背景飞机仍不计全网收益。
