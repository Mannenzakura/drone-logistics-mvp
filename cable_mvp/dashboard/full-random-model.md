# 全入口随机需求与逐架网络传播

全随机指所有货运需求入口随机，而不是把设备数、班次规则和物理参数也随机化。A、C→D、C→E、D→B、E→B分别按可修改的泊松到达率生成独立源需求；A出发时间、其目的地D/E/B、货物类型与数量随机。C源飞机目的地可以为本分支终点或B；D/E源需求去B。每架只在源入口生成一次，之后通过真实离站时刻加航段飞行时间传播至下游，沿用同一ID，不在下游重新抽样这一架。货组归类为普通/快件/医疗，比例和收费倍率均为演示假设，不是实测；样本与模型参数可下载。

默认源需求生成至24分钟，后续班次继续处理积压。A平均0.2架/min，C两向各0.08，D/E各0.08。相邻间隔为-ln(1-U)/λ，目的地和货量按独立随机流生成；同种子可复现。不截断泊松分布或拒绝不成功样本；单样本超过128架会明确报错，需减小到达率或时段。所有需求率为0则合法空网络；没有A→B飞机时不注入虚拟目标。

C源飞机与A到达机共用C作业设备，按到达时刻先到先服务；D/E暂无共同设备限制，作业可并行。每条出站航线有本地与中转FIFO，本地按先到先服务先占本班已可用位置；本地队首未就绪时暂停该本地队列，剩余位次允许中转队列使用。总规模M扣除预留R和外生1架领队后最多M-R-1架货运飞机；领队不计源需求货量。取消班次不清空队列。相同飞机进入下游后属于中转需求，D/E本地源需求先占空位，再服务中转；各类队列不超越未就绪队首。

货量直接决定背景机装卸时长。默认固定任务阶段不执行新增的路线+装卸量+可靠性联合优化；A→B中最早到达C的一架作为追踪对象，其随机货组与装卸需求固定执行。目标机沿生成的分支，电费、巡航编队节能、货组时效/装卸费沿用旧公式，只对该追踪对象计算；不能把它称作全网利润。其他飞机的货物和交付量逐架统计。追踪对象无法完成或超电量会显示失败，不隐藏整个网络。无目标时经济专题显示不适用，原有固定目标算例模式可继续访问全部旧优化/配对/敏感性专题。

等待统计对源需求和上游传入需求按实际到站与发车计算。全网络重复试验重新生成所有入口和全部飞机任务；每次飞机数、目的地和货物均可不同，因此只报告网络完成量、完成货量、滞留和未完成比例，不能把它当成固定任务可靠性。当前只有随机需求，不额外随机化故障、天气或飞行物理参数。班次时刻与设备配置仍由用户给定。末班后的等待属未完成需求，不把未完成者计为零等待。

货物作业计时保留高度相关绞盘计时开关。网络完成货量是排程层的交付统计，背景机尚未逐架核验续航；不得将其称为已验证的全机队物理可行运力。队列统计按该航段末班截止，截止后到达单列，未服务等待只给出下界。
