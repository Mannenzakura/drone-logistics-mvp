## A→C→D→B 双中转点延迟传播仿真

在 `network/` 有独立页面。每架飞机有固定身份与计划到达 C 的时刻；C 点按到达先后排队，作业未完成的队首机阻止后机越过（严格 FIFO，可能留下空位）。C 实际离开时刻加 C→D 飞行时间与额外飞行延迟，得到 D 实际到达时刻；D 再按照本点到达、作业完成、编队时刻和空位进行同样排队，最终得到 B 到达时刻。所有时间都是同一仿真时钟上的分钟；不再给 D 点独立生成与上游无关的到达流。

页面始终计算一条无扰动基线，并用给定随机种子计算扰动情景。扰动分别作用于 C 到达、C 作业、C→D 飞行、D 作业和 C/D 编队取消。种子、计划和参数相同则逐架结果相同；扰动上限和取消概率均可设为 0，得到确定性情景。默认概率只是机制演示，不是事故或晚点数据估计。每架显示 C/D 出发、滞留、B 到达以及相对基线晚点；动画逐架读取同一条仿真结果，不使用另造的演示轨迹。未在给定末班前登编的飞机记为未送达，而不是凭空增开班次。

该页用于检查 v2.4 的独立稳态队列近似可能遗漏的跨站延迟传播。它尚未对多架飞机的 d,l 或航线做联合优化，也不把随机事件概率解释为真实风险。检验命令：`node tests/test_network.mjs`；浏览器页面检查见 `tests/check_network_ui.html`。
