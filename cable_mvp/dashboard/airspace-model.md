# 机场外独立卸货区选项

新增外生情景参数 shared_airspace（记作 s∈{0,1}），由用户选择，不是优化器自由选择的决策变量。
默认 s=1 保持旧模型。s=0 表示机场外独立卸货区，并明确假设该作业不影响机场起降。
地理上位于机场之外，本身不能保证空域互不干扰；这是模型输入条件。

设作业时间 T=t0·z+td·d+tl·l。原有装卸量 d、l 和作业开关 z 的含义保持不变。

- 始终要求 T≤W（编队衔接前的可作业时间）。
- s=1 时要求 T≤H，z≤a；H 为机场共享空域的兼容连续作业窗口，a 为该窗口是否可用。
- s=0 时删除上述两项机场共享资源约束；不把 H 或 a 解释为独立卸货区的许可。
- 机场共享空域占用时间为 s·T。所有载荷、货仓、需求、能量与收益约束保持不变。

独立卸货区默认可用，其局部空域、地面接货能力与作业安全条件视为已满足；未引入多机排队容量或往返该区域的新增飞行时间、能耗。若存在明显绕飞，应进一步加入转移时间与能耗，不能直接把本情景结果作为实地结论。

界面在 s=0 时禁用 H 与 a 输入，并将对应约束显示为“不适用”，保留输入值以便切回共享模式。图中 C 的作业区改为独立卸货区标签；位置仅为示意，不构成机场内外真实地理边界。

回归例：W=6、H=0、a=0，其余默认。共享模式不能索降；独立模式得到 d=5 kg、l=10/3 kg。独立模式下 W=1 仍不能完成固定作业；单飞基准额外电量为零且无编队节能时仍不能作业。
